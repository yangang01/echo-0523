# 七夕 H5「Y × U 双星引力叙事」动效重构设计

## 1. 背景与目标

当前「0523 回音星核」已经包含八个内容场景和实时粒子主视觉，但移动端体验仍有三个明显问题：

1. 首幕长按三秒容易触发浏览器的文字选择、复制或系统上下文菜单。
2. 章节内与章节间存在大量重复点击，体验更像依次操作网页控件，而不是观看一段具有仪式感的视觉短片。
3. 现有星轨长期以相似方式旋转，虽有装饰效果，却没有承担明确的情感叙事；八幕粒子变形和场景切换也缺少连续镜头感。

本次重构将用户首字母 `Y` 与对方字符 `U` 设为两个持续存在的引力核心，以「双星从相遇、扰动、锁定到同频」贯穿八幕。作品仍保持原有称呼、日期、内容结构和情感原则，但把主要体验从“连续点击”升级为“自动演出为主，少数手势具有明确意义”的移动端电影式 H5。

## 2. 已确认的设计方向

- Y/U 造型采用「隐喻式双星轨迹」：第一眼是抽象、高级的星轨，仔细看才能发现 Y 融入 U，不制作直白的字母 Logo。
- 开场采用「引力拖拽」：将 Y 光点拖近 U，引力自动完成剩余吸附过程。
- 整体节奏采用混合式：正文和场景动画自动演出；读完后上滑可立即转场，12 秒无操作时自动继续。
- 八幕运动系统采用「双星引力叙事」：星轨是关系状态的可视化，不再是固定装饰环。

## 3. 体验原则

### 3.1 观看优先

用户不需要为了让内容继续出现而反复点击。正文、粒子、镜头与场景内反馈由统一时间线自动播放，用户只在动作本身具有情感含义时操作。

### 3.2 操作有意义

正式流程仅保留三类主动操作：

1. 开场拖动 Y 靠近 U，表达第一次相遇。
2. 吃醋场景横向滑动解开失序心跳，把噪声解码为“在意”。
3. 在“小事、吐槽、开心、夸夸”中选择想接通的生活频道。

章节推进使用上滑手势，不再显示“继续航行”按钮。表白日期锁定、偏爱点亮、午间游戏同步、深夜同频与终章展开均随阅读时间线自动发生。

### 3.3 阅读权优先于自动播放

每幕正文演出完成后进入 `READY` 状态：

- 用户上滑立即进入下一幕。
- 12 秒无操作后自动进入下一幕。
- 手指按下、触摸正文、聚焦可交互元素或回看已解锁文字时暂停自动推进。
- 用户结束阅读交互后重新开始完整的 12 秒等待，不沿用即将结束的旧计时。

## 4. 八幕 Y × U 动画叙事

### 4.1 唤醒：第一次相遇

- 黑暗中仅出现分离的 Y 光点与 U 引力井。
- 用户短距离拖动 Y；进入吸附半径后，U 产生引力涟漪，Y 自动沿曲线落入共同轨道。
- 两点交汇产生克制的冲击波，粒子从纵深空间展开第一片宇宙。
- 不再出现长按三秒或触碰三次的备用文案。

### 4.2 吃醋：轨道扰动

- 外界赞美化为靠近 U 的亮色掠过粒子。
- Y 的轨迹出现紫红偏移、节拍错位与心跳噪声，表现吃醋，但不呈现控制或占有。
- 用户横向滑动一个连续波形，噪声逐步被解码为“因为在意”。
- 不提供额外“发送脉冲”点击按钮。

### 4.3 表白：锁定 0523 坐标

- Y 与 U 的运动轨迹在空间中自然交叉三次。
- 三个交点先后显影为 `2026`、`05`、`23`，随后组合成 `2026 · 05 · 23`。
- 坐标锁定由时间线自动完成，不要求依次点击三个日期按钮。
- 最后一束坐标光成为下一幕共同轨道的轴线。

### 4.4 偏爱：唯一引力中心

- U 成为画面唯一引力中心，远处无关星点降低亮度并离场。
- Y 留下的七层轨迹自动开放为抽象花瓣状星群，表达“被偏爱的感觉”。
- 轨迹层级随正文逐段点亮，不再要求连续点击三次。

### 4.5 回应：接住生活信号

- U 发出生活信号，用户只选择一次频道：小事、吐槽、开心或夸夸。
- 频道选定后，对应正文自动逐段播放；每段文字转化为从 U 发出、被 Y 接住的回音粒子。
- 原有三类回应语义继续影响轨迹质感，但不再要求逐个点击三种回应按钮。
- 频道选择仍决定本次完整阅读路径和后续视觉生长数据。

### 4.6 陪伴：双轨同行

- Y 与 U 化成两条平行光流，沿同一条粒子隧道前进，呼应午休一起打游戏的日常。
- 镜头沿双轨自动穿越三个空间门，分别对应靠近、同步和穿越。
- 不显示三阶段游戏按钮；场景仍保留明确的进度反馈，但表现为沿轨道自动点亮的三个门。

### 4.7 深夜：呼吸同频

- 两条轨迹转为电话声波般的缓慢呼吸，开始时稍有相位差。
- 随正文阅读时间，波形自然从 0% 靠近至 100%，最后叠成一条稳定同频光线。
- 完全移除按住连接与触碰三次的交互，也不再使用百分比按钮式界面。
- 页面进入后台时停止同频进度，回到前台后从原位置继续。

### 4.8 终章：Y 融入 U

- 前七幕留下的轨迹从画面边缘回流，先形成隐约的 Y，再落入 U 的开口。
- Y/U 星徽完成后旋转并展开为无限轨迹，最终稳定定格 `05:23`。
- 终章正文、关系计时与署名随星徽完成自动显现，不再要求三次“读取回音”。
- 保留“重新进入这片宇宙”，因为重玩是一个明确且不可自动触发的用户决定。

## 5. 连续镜头与场景状态

WebGL 世界在整个体验中只创建一次。Y 核心、U 核心、轨迹系统、粒子系统、镜头与后期效果持续存在，场景切换不卸载或重建画布。

每幕由统一编排状态驱动：

1. `ENTER`：接收上一幕的最终几何结构和镜头动量。
2. `PRESENT`：播放本幕粒子、轨迹、镜头、正文与声效时间线。
3. `READY`：正文已读完，显示轻量上滑光迹并启动 12 秒自动推进计时。
4. `EXIT`：把当前结构收束成下一幕的入口结构，期间锁定重复推进。

转场持续 1.6–2.2 秒。八次转场采用不同的空间动作，例如吸附、扰动复位、坐标锁定、花瓣开放、回音回收、轨道穿越、波形叠合和无限展开，但始终保留 Y/U 两个引力核心的连续位置关系。不得使用简单的整页淡出后更换背景作为主要转场。

## 6. 页面与文案布局

- 根容器使用动态视口高度和安全区变量，适配移动 Safari、Android 浏览器及带底部工具栏的内置浏览器。
- 顶部品牌、声音按钮、右侧八幕进度和底部上滑提示固定在安全区域内。
- 正文玻璃面板默认只展示当前回音段落，以减少对粒子主体的遮挡。
- 已解锁的旧段落收束为轨道旁的微光刻度；用户可点选回看，但回看不推进场景，也不重置已完成叙事状态。
- 场景主标题、当前正文和核心动作必须在 390 × 844 CSS 像素视口内同时可见，不能依赖页面纵向滚动完成主流程。
- 删除所有 `继续航行`、分阶段点击计数和无语义的完成按钮。

## 7. 输入与移动端行为

### 7.1 开场拖拽

- 仅在 Y 光点拖拽命中区域设置 `touch-action: none`、`user-select: none` 和移动端长按菜单抑制。
- 普通正文区域不全局禁用文字选择。
- 拖拽使用 Pointer Events，同一逻辑支持触摸、鼠标和触控笔。
- 吸附依据距离阈值判断，不要求用户精确拖到单点。
- `pointercancel`、页面隐藏、窗口失焦和组件卸载均必须停止手势并清理捕获状态。
- 键盘用户可聚焦 Y 光点，并用 Enter 或空格触发等价吸附；不支持 Pointer Events 时提供一次轻触备用入口。

### 7.2 上滑推进

- 同时判断纵向距离、方向优势和速度，过滤轻微抖动、横向滑动与正文回看操作。
- 只有 `READY` 状态接受章节推进手势。
- 一次手势最多推进一幕；`EXIT` 期间忽略后续手势。
- 桌面端保留鼠标滚轮向下和键盘方向键作为等价输入，但不显示常驻按钮。

## 8. 系统边界与数据流

重构后拆分为以下职责单一的模块：

- `ExperienceDirector`：管理四阶段场景状态、12 秒计时、暂停原因和一次性推进门控。
- `GestureSurface`：统一拖拽、横向解码、上滑、滚轮和键盘输入，输出语义事件，不直接修改章节状态。
- `TwinGravityCanvas`：维护 Y/U 核心、轨迹、粒子、镜头和后期效果，并消费导演发出的动画 cue。
- `SceneTimeline`：定义每幕的入场、正文节点、视觉节点、完成时间和退场动作。
- `EchoTranscript`：展示当前回音、旧回音刻度和读屏 live region。
- 现有内容与 reducer：继续保存频道选择、已解锁文字、成长数据、章节顺序和重玩状态。

主要数据流为：

```text
Pointer / Wheel / Keyboard
          ↓
    GestureSurface
          ↓ semantic event
  ExperienceDirector ─────→ SceneTimeline
          ↓                       ↓
   experience state        visual / copy cues
          ↓                       ↓
   EchoTranscript      TwinGravityCanvas
```

手势回调只发送语义事件，如 `OPENING_ATTRACTED`、`JEALOUSY_DECODED`、`CHANNEL_SELECTED` 和 `ADVANCE_REQUESTED`。粒子实现不得反向控制 React 场景状态。

## 9. 性能、降级与可访问性

- 延续高、中、低三档质量；低档减少粒子和辉光采样，但 Y/U 主轮廓与连续转场语义必须保留。
- Y/U 核心与关键轨迹使用独立低顶点几何，不能因粒子预算降低而消失。
- 持续低帧率时只在稳定检查点降档，不在转场中途替换材质或重建画布。
- WebGL 不可用时使用 CSS/SVG 版 Y/U 星徽和柔和溶解转场，所有正文与频道选择仍可完成。
- `prefers-reduced-motion: reduce` 下取消镜头冲刺、快速旋转和粒子爆发，改用 300–500 毫秒的缩放与溶解；不删除内容或操作反馈。
- 页面隐藏时暂停 requestAnimationFrame、自动转场、同频进度和声音；恢复后从记录的稳定时间继续。
- live region 始终挂载，每段新正文只播报一次；装饰轨迹和粒子对辅助技术隐藏。
- 所有可操作目标具有可见焦点，且至少满足 44 × 44 CSS 像素命中范围。

## 10. 验证策略

### 10.1 自动化行为测试

- 开场真实移动手势：`pointerdown → move → pointerup` 完成吸附且只完成一次。
- 未进入吸附距离、`pointercancel`、页面隐藏和卸载均不误完成，并清理捕获与计时。
- 开场 DOM 不存在长按三秒、触碰三次或会重复计数的合成 click 路径。
- 上滑必须达到方向、距离或速度契约，且只在 `READY` 推进一幕。
- 正文触摸与回看暂停 12 秒倒计时；结束后重新开始完整计时。
- `EXIT` 期间的快速重复滑动不会跳过场景。
- 四个频道仍生成四条完整内容路径，选择后回应自动播放且成长数据正确累积。
- 场景顺序保持 wake → jealousy → confession → privilege → signal → game → night → finale。
- 终章只能在前七幕完成后开放，重玩清空临时进度并回到开场。

### 10.2 粒子与导演契约测试

- 八幕的 Y/U 位置、轨迹目标和转场 cue 均具有不同且确定的签名。
- 相邻场景的出口目标与入口源结构相容，不先回到随机散点。
- 同一 WebGL canvas 在完整流程中不因场景变化而重建。
- reduced-motion、低质量与 SVG fallback 都保留相同的叙事顺序和最终 Y/U 星徽。
- 后台暂停与恢复不造成时间线跳跃、自动跨幕或音画不同步。

### 10.3 人工视觉门禁

在 390 × 844 CSS 像素的真实移动浏览器或等价设备模式中逐幕验证：

- 开场长触、拖拽与取消不会出现系统文字选择、复制浮层或上下文菜单。
- 主标题、当前正文、Y/U 主视觉和上滑提示在安全区内，无浏览器工具栏遮挡。
- 八幕转场肉眼明显不同，但 Y/U 两个核心位置关系连续。
- 星轨在每幕都能解释其情感含义，不存在仅为装饰的固定绕圈。
- 低档质量仍清晰识别 Y/U 关系，且动画流畅度优先于粒子数量。

## 11. 验收标准

- 首幕完全取消长按三秒，移动端不触发选择、复制或上下文菜单。
- 主流程不再显示“继续航行”，除频道选择和重玩外不依赖连续点击按钮。
- 用户可通过上滑掌握阅读节奏；12 秒自动推进不会在触摸或回看正文时发生。
- Y/U 是整个体验中持续存在的两个视觉主体，并按八幕语义发生可辨识变化。
- 场景间为 1.6–2.2 秒连续几何转场，不是简单页面淡入淡出。
- 第八幕完整呈现 Y 融入 U 的隐喻式星徽，并与 `05:23`、称呼和署名共同定格。
- 完整自动化测试、lint、静态 Pages 构建和产物验证通过。
- 390 × 844 移动端逐幕走查通过后才发布到公开 GitHub Pages。

## 12. 非目标

- 不修改已经确认的称呼“小宝贝”、表白日期 `2026-05-23`、署名“永远爱你的人”和核心文案方向。
- 不新增照片、账号、云端数据、聊天服务或真实消息系统。
- 不要求陀螺仪权限；设备倾斜只能作为可选的轻微视差增强。
- 不复制参考视频中的玫瑰、奶茶或具体代码效果。
- 本次设计不选择或下载新的背景音乐；音频轨道可在独立设计确认后接入同一导演时间线。
