# 第五幕即时反馈与可跳过设计

## 目标

只修正第五幕“今日信号”的等待体验。用户点击任一频道后应立即确认选择，并可马上进入第六幕；其余七幕的自动播放、阅读节奏与转场逻辑保持不变。

## 已确认的根因

第五幕当前在选择频道后固定播放 41.2 秒回应，完成后还要等待 12 秒自动推进，再播放 1.85 秒退出转场。用户在约 55 秒内无法通过继续点击选项加速，因此移动端看起来像点击失效或页面卡住。

## 交互设计

- 点击任一频道后立即锁定该选择，选项区立即替换为“频道已接通 · …”反馈面板。
- 第一条频道回应在同一次点击流程中立即显示，不再等待 1.2 秒。
- 反馈面板同时显示一个真实按钮，文案为“进入下一幕”；按钮具有至少 44×44 CSS 像素的点击区域。
- 点击按钮立即请求第五幕退出，并沿用现有 1.85 秒电影转场进入第六幕。
- 用户不点击按钮时，其余频道回应继续按现有时间线播放，保留完整内容体验；现有自动推进仍作为兜底。
- 快速重复点击频道或“进入下一幕”只推进一次，不重复记录回应或跳过第六幕。

## 实现边界

- 只改 `SignalScene`、第五幕到导演层的推进接口、第五幕按钮样式及对应测试。
- 不缩短或改写其他场景的时间线。
- 不改变频道内容、粒子生长类型、音乐、场景顺序和现有上划操作。
- 第五幕提前退出时清理其未触发计时器，不能在第六幕后继续写入回音状态。

## 测试与验收

- 单元测试：点击频道后立即出现频道接通提示、第一条回应和“进入下一幕”按钮。
- 集成测试：按钮点击后仅经过第五幕既有退出转场即进入 `06 / 08`，无需等待 41.2 秒和 12 秒空闲期。
- 幂等测试：连续点击频道或推进按钮不会重复触发选择、回应或场景推进。
- 清理测试：提前离开第五幕后，剩余回应计时器不再触发。
- 回归测试：未点击推进按钮时，第五幕仍能播放全部回应并自动进入第六幕；其他场景的时间线测试保持通过。
- 移动端检查：390×844 与 390×650 视口下，频道接通提示和推进按钮可见、可点，不被 Safari 底部工具栏遮挡。
