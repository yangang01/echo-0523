# 全场景手动滑动阅读设计

## 目标

把八幕正文从定时播放改为完全由阅读者控制。保留当前特色互动和短暂电影转场；删除正文解锁、正文切换和非终章自动推进的长时间计时。阅读者通过左右滑动翻阅正文，到达末段后才解锁上划进入下一幕。

## 统一交互模型

- 每幕正文使用同一个滑动字幕组件。
- 左滑进入下一段，右滑返回上一段；到达边界时保持当前段，不循环跳转。
- 底部标记展示总段数和当前段。已经到达的段落可点击标记回看，尚未到达的段落保持锁定。
- 首次到达最后一段时记录该幕已经读完；之后即使右滑回看，下一幕入口也不重新锁定。
- 读完前，上划、滚轮、键盘换幕命令均不推进场景。
- 读完后显示真实按钮“上划进入下一幕”；点击该按钮或在字幕区域外向上滑都会调用同一个幂等推进操作。
- 字幕区域通过手势方向判定只处理水平滑动，不把左右翻页误判为上划换幕。
- 桌面端左右方向键翻阅正文；按钮、上方向键或 PageDown 进入下一幕。

## 特色互动边界

- 第一幕保留拖动 Y 靠近 U；成功后立即显示第一段正文。
- 第二幕保留心跳滑杆解码；达到完成阈值后立即显示第一段正文。
- 第五幕保留四个频道选择；选择后立即锁定频道、显示对应第一段正文和频道回应。
- 其他当前没有通关操作的场景，在入场短动画结束后立即显示第一段正文。
- 特色互动只决定“何时开始阅读”，不再启动正文计时器。
- 场景入场和退出仍保留现有约 0.65–2.1 秒的视觉转场时间；它们不负责正文阅读或自动推进。

## 场景完成与终章

- 非终章：首次到达末段时将导演状态置为 ready，但不设置自动退出时间。ready 状态只响应显式点击、上划或键盘推进。
- 第八幕：到达最后一段后显示最终文案和“重新进入这片宇宙”，不显示下一幕按钮，也不接受上划推进。
- 第五幕此前新增的即时“进入下一幕”按钮被统一入口取代；选择频道后不能跳过未读正文。
- 快速重复滑动、点击或按键只能推进一个文本索引或一次场景，不能跳段、跳幕或重复记录回音。

## 状态与组件边界

- `EchoTranscript` 负责当前正文索引、水平手势、键盘翻页、已到达段落标记和“到达末段”通知。
- 场景组件只负责特色互动完成后解锁第一段；不再维护正文播放计时器。
- `DirectedScene` 接收末段通知，完成当前场景并解锁统一换幕入口。
- `GestureSurface` 继续负责字幕区域外的上划、滚轮和键盘换幕；只有导演处于 ready 时才启用。
- `sceneTimelines` 只保留入场、退出和视觉 transition 数据；正文 reveal 时间与 `presentMs` 不再参与运行时导航。
- 现有回音内容、频道分支、粒子生长、音乐、场景顺序和视觉主题不变。

## 异常与无障碍处理

- 指针取消、窗口失焦或页面进入后台时清理字幕手势所有权，不产生翻页。
- 水平位移未达到阈值或方向不明确时保持当前段。
- 按钮点击区至少 44×44 CSS 像素，并具有清晰的 `focus-visible` 样式。
- 字幕更新继续使用礼貌的 live region，避免每次手势产生重复播报。
- `prefers-reduced-motion` 下缩短字幕切换动画，但不改变解锁和导航规则。
- 390×844 与 390×650 视口下，当前正文、段落标记和换幕按钮必须可见可操作。

## 测试与验收

- 字幕组件：左右滑动、左右方向键、边界保持、未读标记锁定和回看行为。
- 手势冲突：字幕内水平滑动不会触发上划换幕；字幕外上划在末段前无效、末段后有效。
- 特色互动：第一、二、五幕完成互动后立即出现第一段，等待任意时长都不会自动切换正文。
- 自动场景：第三、四、六、七幕入场后显示第一段，等待任意时长不自动翻页或换幕。
- 场景完成：首次到达最后一段后出现统一换幕按钮；回看较早段落后入口仍保持解锁。
- 终章：最后一段显示最终文案和重新体验按钮，不出现下一幕入口。
- 幂等与清理：快速重复输入不跳段、不重复推进；卸载和前后台切换不遗留手势状态。
- 回归：全套单元测试、lint、GitHub Pages 构建和产物验证通过，并在两档移动端视口完成实际交互检查。
